# Blocks

Blocks is a personal Android app (Kotlin, Jetpack Compose, Hilt) that plans and tracks a day as a sequence of blocks.

## Docs

Start with [docs/SUMMARY.md](docs/SUMMARY.md). The living docs are in `docs/`; the current task is `docs/Task-8.md`.

## Build and install

```
./gradlew installDebug
```

Debug installs as `com.roni.blocks.debug`. The release variant is the owner's daily app.
