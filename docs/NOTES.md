# Notes - decisions the task files left unspecified, and what the code does instead

NOTES.md crossed 20 KB, so the older Task-1..7 entries are condensed. Still-live rules first, then the decisions a future agent needs.

- **Restore is idempotent, single-flight, and always completes.** `DayOrchestrator.ensureRestored()` takes a mutex and sets `_isRestored` in a `finally`; every entry point awaits it first, so a throwing restore can't strand the app.
- **`onTimeTravelled()` is new, and deliberately not `onTimeChanged()`** (Task-6.md:376 expects a 20:05 jump to reach `KidTime`; `onTimeChanged()` never applied missed transitions). It replays the skipped transitions exactly like a cold start and also applies the date rollover (`applyRollover()`); `SystemEventsReceiver` calls it, `AlarmReceiver` keeps `onAlarm()`. All replay loops are bounded by `MAX_REPLAY_STEPS`.
- **The old splash bug was a write/read form mismatch in `DayStateSerializer`**, not a race: direct `serialize` calls produced the POLY_OBJ array form while reads expected the object form. The wrapper now delegates via `encodeSerializableValue`/`decodeSerializableValue` and decodes legacy array payloads with a private `arrayJson` (`ignoreUnknownKeys`, `useArrayPolymorphism`).
- **Test harness:** `PrefsStorage` takes `@IoDispatcher`; tests pass `UnconfinedTestDispatcher()` so every write commits before the assert. `robolectric.properties` sets `application=android.app.Application`: unit tests get a plain Application, no Hilt graph, no background restore racing the seed. Race tests use `Dispatchers.Default` + `withTimeout(5_000) { .first { } }`. `@IoDispatcher`/`@ApplicationScope` qualifiers live in `core/di/CoroutinesModule.kt`.
- **Today's plan (`TodayPlan(templateId, blocks, edited)`) is the 2.0.0 data model**: the orchestrator owns it (`todayPlan` StateFlow), `timelineAt` reads it, swap rebuilds via `SegmentBook.swapPlan`. 1.5.1 saves migrate via `migratePlan` + `repointBlockIndex`; `PLAN_STARTS_AT` pref is gone. `HistoryManager.observeDay` is version-driven.
- **Weekly** renders `rows: List<PlanProgressUi>` with a `missedSummary` line; chart card uses `Spacing.l` (16dp), not `m`.
- **Time Debt is gone** (Task-7 Slice 4): `DebtRecord`/`writeDebt`/`readDebt` deleted; Weekly/Insights/History compute `debtMinutes(segments)` directly. `debtMinutes` stays.
- **DayRecap** rows anchor on the record's `plannedBlocks`; summary = worked(non-paused) CV/Coding/Gym ÷ planned, capped 100%.
- **Pomodoro**: the spec's new `PomodoroPhase` collides with the engine's existing one, so the new type is `PomodoroSlot`. `HourHeight` 64→80dp.
- **Plan editing**: `DayOrchestrator.editPlan(PlanEdit)` is Running/Paused-only, edits in memory then `persist()` once + silent `sideEffects()`. `PLAN_EDITED` comes from `todayPlan.edited` at flush. Calendar editing: tap selects, five `HomeAction` editing messages, handles at `zIndex(2f)`, `EdgeHandle` is the spec's sample. Type tags use the data-object names because `BlockType` is a sealed interface.
- **Demo data** (28 days): a late-start day and an edited day built through the same pure pieces; both Sun/Tue/Wed. `PLAN_EDITED` only added when `PlanEditor` actually returned a plan.
- **Naming/doc facts**: `TimelineQueries.kt` is a file of `ScheduleEngine` extensions, not a class; there is no `InsightsManager` (it's `InsightsViewModel`); Settings copy stays as inline literals (deliberate deviation from Task-6 wording); `SettingsRow.enabled` gates the developer rows off in release; the emergency "Stop today" confirmation is always shown and only Pause supports "Don't ask again"; `NowButtonId.EMERGENCY` renders as its own centered `now_emergency` TextButton so Pause · Next stay equal-width 48dp; `TimeFormatter.label/hourGutter` are the single 12/24h source of truth; `BlockType.isWork` lives in `Model.kt`.
- **Test count baseline**: Task-7 ended at 211 tests. Task-8 Slice 1 removed Roborazzi and the screenshot/layout-only tests.

## Task-9 (2.2.0)

- `reactedAt: Instant?` lives on the orchestrator (private, persisted, reset on rollover). User actions set it; alarms and `applyRollover` don't. `AlertPlanner.next` takes `reactedSec` so nags stop once Roni reacted. `App.onCreate` adds a `ProcessLifecycleOwner` observer that calls `onAppForeground()` on `onStart`.
- `ScheduleEngine.nextWakeUp(state, date, now, template, index, anchor?)` — `anchor` defaults to null. `nextBoundary` starts its Pomodoro cursor at `anchor ?: block.plannedStart`. The orchestrator passes `wakeAnchor()` (the open PLANNED segment's actualStart, null when SYNTHETIC_FREE — `Done early` parks the Pomodoro and the wake is the free time's planned end). Pomodoro wake-ups now match the notification's Pomodoro after a late start.
- Notification's `render(model, transition, alert=false)` — alerts always sound (`FLAG_ONLY_ALERT_ONCE` cleared), transitions only when not foreground, refreshes stay silent. `dismissals.forget(key)` happens on transition or alert.
- `NotificationModelMapper.running` branches done-early / Pomodoro / non-Pomodoro. Done early: key `$id:early`, title `Free time · <name> done early`, text `until HH:MM · then <next>`, `countdownTo = open.plannedEnd`, action `Next: <next>`. Pomodoro focus: title `<name> · Focus i/T`, text `Break at HH:MM · ends HH:MM` (boundary from `AlertPlanner.pomodoroBoundaries`, ends = block end). Pomodoro break: text `Focus i+1/T at HH:MM · ends HH:MM`. All other running: text `until HH:MM · then <next>` (no `then` when there's no next block).
- `DayOrchestrator.sideEffects(transition, alert)` schedules `min(nextWakeUp, AlertPlanner.next(..., afterSec=now))`. `onAlarm` adds a 90s grace via `AlertPlanner.due(...)` and forwards `alert != null` to the renderer.
- `Ticker.minutes` polls every 1s with `distinctUntilChanged()`, so a debug-clock jump shows within a second.
- `PlanEditor.editMode` for the current unfinished work block returns `END_AND_TYPE`; the end stepper and the work-type chips (CV / Coding / Gym, no Free) are both rendered. Retype to Free is refused: that's "Done early".
- `DayOrchestrator.editPlan` updates the open segment to follow the new plan: an open PLANNED with `blockId == current.id` takes the new `plannedEnd` and the new `type` when retyped; an open `SYNTHETIC_FREE` (no blockId) takes the current block's new end.
- New `DayOrchestrator.liveRecord(): DayRecord` and `correctPast(edit): Boolean`: `RecordEditor.apply(liveRecord().toRecordRows(zone), edit, limitMin)` where `limitMin` is the open segment's start (or now). `withRows(...)` sets `book.segments` and adds `CORRECTED` to the flags. Works in every state that has segments, kid time and the evening included.
- Home: tapping a past block (or any day block once kid time / evening started on Sun–Thu) opens `CorrectBlockSheet` for the row from `DayRecapMapper.map(day.liveRecord(), use24)` matched by id; a row whose `fix == NONE` shows the kid-time message. Past blocks show their recap row as subtitle (`Done HH:MM–HH:MM` or `Missed`). The three "nothing triggers any more" messages (`LOCKED_OVER`, `LOCKED_FINISHED_EARLY`, `LOCKED_FREE_RUNNING`) are gone.
- `EditCard` stepper rows are −15 / −5 / +5 / +15 (one row, equal weight). `END_AND_TYPE` caption: "This block is running. Change when it ends or what it is; Done early ends it now." `END_ONLY` caption: free time — "End free time sooner to start the next block sooner."; otherwise "<Type> finished early; this is free time until HH:MM."
- Widget accent strip is now an `<ImageView>` (RemoteViews can't inflate a plain `<View>`); `setInt("setBackgroundColor", ...)` keeps working. Robolectric smoke test `widgetLayout_inflatesAsRemoteViews`.
- `com.roni.blocks.debug` is the only phone ID (`Phone: only com.roni.blocks.debug. Never install over, clear, force-stop or uninstall com.roni.blocks.`).
- Tests added: `NotificationModelMapperTest.{doneEarly_showsFreeTimeAndTheRealNextBlock, pomodoro_showsTheRoundAndTimeToBreak, running_focus_countsDownToTheBreak_withPause, running_blockWithoutPhases_namesTheNextBlock}`; `HomeViewModelTest.doneEarly_saysFreeTimeAndNamesTheNextBlock`; `ScheduleEngineTest.nextWakeUp_followsTheRealStartOfAPomodoroBlock`; `DayOrchestratorTest.{alarm_fiveMinutesBeforeTheEnd_alerts, nags_stopOnceRoniReacts, correctPast_fixesAnEarlierBlockWhileTheDayRuns, correctPast_neverReachesTheRunningBlock, editPlan_retypesTheRunningBlock, editPlan_doneEarly_movesTheFreeTimesEnd}`; `NotificationRendererTest.alert_makesASound_evenInTheForeground`; `WidgetLayoutTest.widgetLayout_inflatesAsRemoteViews`.
